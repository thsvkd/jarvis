# Jarvis 콘텐츠 구성 랩 03

기존 Bento의 헤더·폰트·색상·카드·계기·차트·서비스 상세 창을 재사용한다.
시안 간 차이는 콘텐츠 순서, 초기 공개 범위, 탐색 방식이다.

| 시안 | 처음 보이는 내용 | 전체 정보 접근 |
|---|---|---|
| 01 요약 후 펼치기 | 기존 개요·경보·계기, 서비스 6개 | 나머지 서비스 펼치기, 맵·하드웨어·네트워크·런타임 접기 |
| 02 업무별 탭 | 기존 개요 | 개요·서비스·하드웨어·네트워크·런타임 5탭, 키보드 이동 |
| 03 서비스 먼저 | 공개 앱 검색·카테고리·카드 | 전체 필터, 나머지 카드 펼치기, 아래 운영 개요·상세 접기 |
| 04 경보·변경 먼저 | 기존 경보와 구성 변경, 개요, 문제 서비스 | 전체 서비스 보기, 하위 상세 접기 |
| 05 카테고리별 접기 | 기존 개요, 서비스 분류별 개수·상태 | 분류 펼치기, 검색·필터 시 해당 카드 자동 공개 |

갤러리 `/lab/`, 독립 데모 `/lab/proposal/?concept=focus` (inbox/library/rooms/pulse).
동일한 LAN/Tailnet Jarvis 서버에서 제공한다. 운영 홈은 `/`.

## 원본 재사용

`tools/build-lab.py`는 `static/index.html`에 랩 CSS·로더·설명만 추가한다.
`proposal.js`는 기존 노드를 이동하거나 감싸며, 실제 렌더링은 `app/bento.js`와 `app/home-map.js`가 맡는다.
Focus 개선판의 UI는 운영 홈과 `app/focus.js`·`app/focus.css`를 공유한다.
생성 시 운영 배치 로더 `app/focus-layout.js`를 제외해 각 시안의 배치를 유지한다.
원본을 수정하면 생성 HTML도 갱신해야 한다.

```sh
python3 tools/build-lab.py
python3 tools/build-lab.py --check
```

실험 화면의 테마·지도 관점·필터는 시안별 sessionStorage에만 저장한다.
후보 저장은 `jarvis.lab03.favorite` localStorage를 사용한다. 운영 화면의 설정 키는 수정하지 않는다.

## 실제 데이터

갤러리가 5초마다 수신한 동일한 스냅샷을 미리보기와 비교 화면에 공유한다.
임베드 화면은 자체 스냅샷 폴링을 하지 않는다. 실제 1h/24h 이력도 부모를 통해 요청하고 동시 요청을 합친다.
독립 데모는 기존 Bento 클라이언트의 3초 갱신과 이력 조회를 사용한다.
통신 실패·지연 처리는 기존 클라이언트를 따른다. 가상 수치를 사용하지 않는다.

## 검증

```sh
node tools/check-lab.mjs http://100.64.0.2:9300 /tmp/jarvis-lab-check
```

갤러리와 기존 5시안·Focus 개선판을 각각 1440×900·390×844에서 실행한다.

미리보기의 동일 스냅샷·자체 폴링 없음·운영 설정 격리를 확인하고 PNG와 JSON 보고서를 저장한다.
콘솔 오류·요청 실패·가로 넘침·상호작용 실패는 비정상 종료한다.
Host와 Cloudflare 헤더 접근 제한은 기존 서버와 동일하다.

## Focus 개선판 (01+)

`/lab/proposal/?concept=focus-plus`는 기존 Focus와 나란히 비교할 수 있는 별도 시안이다.
갤러리에는 기존 5종과 개선판을 함께 표시하고, 기본 비교 쌍은 Focus / Focus 개선판이다.

- 첫 화면은 분류별 대표 서비스 최대 6개로 시작한다. `고정 서비스 선택`에서 자주 쓰는 항목을 개수 제한 없이 고정한다.
- 선택은 해당 시안 sessionStorage에 저장하며 폴링 때 다시 선정하지 않는다. 사용 이력을 추정하지 않는다.
- 고정 항목이 관측되지 않으면 미관측 개수를 표시한다. 목록 밖의 저하·다운·확인 불가 항목은 상세 바로가기를 제공한다.
- 고정 목록은 한곳에 모으고 카드의 기술 메타데이터·통계를 상세 창으로 넘긴다. 검색·카테고리·전체 보기로 모든 서비스에 접근한다.
- 모바일에서는 기존 분류별 막대와 운영 통계를 접고, 경보 메시지를 간결하게 표시한다. 둘 다 펼쳐 전체 내용에 접근할 수 있다.
- 접기 제목에는 CPU·메모리·루트 디스크 사용률, 온라인 피어/전체, 실행 컨테이너, 실패 유닛, 최근 1시간 변경 건수를 표시한다.
- 누락된 자원 값은 `확인 불가`, 관련 수집 오류가 있으면 `수집 오류`, 수집기 지연은 `수집 지연`, 연결 지연은 `연결 지연`으로 표시한다. 오프라인 피어 수 자체를 장애로 단정하지 않는다.

선택·갱신 후 유지·문제 서비스 접근·누락 값·수집 오류·변경 기간 경계도 브라우저 검사에 포함한다.
