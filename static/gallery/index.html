대시보드 시안 5종

같은 실시간 데이터를 다섯 가지 방식으로 그렸습니다. 미리보기는 각 시안의 1440×900 화면을 그대로 축소한 실제 화면이에요. 마음에 드는 하나를 골라 주세요.

  1. /d/control/
    열기

    01Control Room관제실

    벽면 모니터에 띄워 두고 경보와 서비스 매트릭스를 상시 감시하는 어두운 관제 화면.

    • 상시 감시
    • 다크 전용
    • 서비스 매트릭스
    열기 새 탭
  2. /d/bento/
    열기

    02Bento벤토

    크기가 다른 타일에 핵심 지표를 나눠 담아 한눈에 훑어보는 요약 대시보드.

    • 타일 레이아웃
    • 라이트·다크
    • 한눈 요약
    열기 새 탭
  3. /d/atlas/
    열기

    03Atlas아틀라스

    인터넷에서 앱까지 이어지는 노출 경로를 지도로 펼쳐 보여 주는 화면.

    • 네트워크 맵 중심
    • 노출 경로
    • 연결 구조
    열기 새 탭
  4. /d/ledger/
    열기

    04Ledger레저

    번호 붙은 절과 표로 차분히 읽어 내려가는 신문 지면형 상태 보고서.

    • 에디토리얼 지면
    • 세리프 타이포
    • 표 중심
    열기 새 탭
  5. /d/terminal/
    열기

    05Terminal터미널

    btop·k9s 에서 영감을 받아 키보드로 훑어보는 고밀도 텍스트 대시보드.

    • TUI 스타일
    • 키보드 탐색
    • 테마 3종
    열기 새 탭

  6. 고르는 기준

    어떤 화면이 맞을까요?

    • 01관제실벽 모니터에 띄워 두고 계속 지켜볼 때
    • 02벤토핵심 숫자만 빠르게 확인하고 싶을 때
    • 03아틀라스무엇이 어디로 노출되는지 경로부터 볼 때
    • 04레저보고서처럼 차분히 읽고 기록을 검토할 때
    • 05터미널키보드로 빠르게, 촘촘한 텍스트가 편할 때

    다섯 시안 모두 같은 /api/snapshot 을 받아 하드웨어·서비스·네트워크 맵·인그레스·Tailscale·포트·컨테이너를 똑같이 다룹니다. 다른 것은 보여 주는 방식뿐이에요.
