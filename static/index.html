      기기 · Orca 페어링

      이 core 가 모으는 기기 · 연결은 페어링 코드, 업데이트 확인은 버전 비교, 업데이트는 그 기기 Orca 패키지와 전역 스킬, jarvis 업데이트는 GitHub main 을 받아 그 기기 jarvis 를 재시작

      데스크톱: Orca 의 원격 환경 추가에 코드를 붙여 넣거나 orca environment add --name <이름> --pairing-code <코드>. 모바일: Orca 앱으로 QR 을 찍는다. 대기 코드가 없으면 이미 페어링된 기기의 코드를 보여 준다(그 기기와 자격을 함께 쓴다).

      AI 구독 사용량

      기기마다 Orca 와 cswap(Claude 계정 전환)이 아는 구독 계정의 한도 · 보는 동안 1분마다 갱신, Orca 의 프로바이더 조회는 5분 간격(새로고침은 30초 간격)
