# TEST_SPEC

> **SSoT** — 무엇이 완료인가. 사용자와 합의한 수용 케이스의 유일한 목록.

## 규칙

- 케이스는 `WHEN <조건> THE SYSTEM SHALL <기대 동작>` 형식으로 쓴다. 조건절이 그대로 테스트 이름이 된다.
- 수용 테스트는 아래 케이스를 빠짐없이 커버한다. 구현 내부의 단위 테스트는 이 제약 밖이다.
- 통과는 완료의 필요조건이지 충분조건이 아니다. 일반해를 요구하며, 나열된 케이스만 노린 특수 분기·하드코딩은 미완료다.
- 여기 없는 케이스는 완료 범위 밖이다. 공백을 발견하면 채우지 말고 목록에 넣을지 먼저 합의한다.
- 목록의 추가·수정·삭제는 사용자만 닫는다.
